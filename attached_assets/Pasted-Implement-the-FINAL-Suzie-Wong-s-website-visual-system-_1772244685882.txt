Implement the FINAL Suzie Wong’s website visual system exactly as follows. These instructions replace all previous colour, font, and glow settings.

# 1. IMPORT FONTS

Add to HTML <head>:

<link href="https://fonts.googleapis.com/css2?family=Montserrat:wght@400;700;900&family=Luckiest+Guy&display=swap" rel="stylesheet">

Then upload this font file into:

/public/fonts/Beon-Regular.ttf

---

# 2. ADD FONT FACE

In style.css:

@font-face {
font-family: 'Beon';
src: url('/public/fonts/Beon-Regular.ttf') format('truetype');
}
